# 省考通过！荆医互联网医院开启智慧就医新体验

> 更新时间：2026-09-17 (UTC+8)

6月30日，荆州市互联网医院项目顺利通过省卫健委现场评审。这标志着我院在建设智慧医院，为群众提供便捷化、高效化、智能化的健康服务新模式进程中迈出崭新一步。

评审会上，湖北省卫健委行政审批中心主任郭小玲向与会人员介绍了省卫健委组织开展互联网医院评审的背景及具体要求，并一一介绍了评审组专家。

荆州市中心医院副院长龚道恺从医院信息化建设、互联网医院创建、诊疗科目和科室设置与人员、互联网医院房屋和设备设施、互联网医院规章制度、互联网医院创建成果六个方面，详细向与会专家作了互联网医院建设工作汇报。

随后，专家组分成信息系统建设、互联网建设两个小组，对照评审细则，深入互联网医院、信息中心和机房，通过听取汇报、审阅材料、系统测试、现场演示等形式，对我院互联网医院进行了全面、深入、细致的评审。

反馈会上，评审组专家依次就现场评审进行反馈。专家组经讨论后一致认为，荆州市中心医院互联网医院相关管理制度完善、互联网诊疗流程清晰、数据安全措施到位、推进措施有力、材料准备充分，拟开具诊疗科目及科室设置符合互联网医院基本标准（试行）中相关要求，同意通过现场评审。同时，专家组也对我院互联网医院的进一步完善提出了宝贵建议，希望医院在“互联网+医疗”的探索中做到标准化、规范化、严格化管理，更好地服务人民群众。

长江大学副校长、荆州市中心医院院长毛精华对专家组的辛勤付出和悉心指导表示诚挚感谢。他表示，医院将以此次现场评审为契机，认真落实、整改各位专家提出的宝贵意见和建议，积极探索“互联网+医疗”新模式，让人民群众切实享受到“互联网+医疗健康”创新成果带来的实惠，为全省互联网医疗健康发展提供有益的探索和实践，为健康荆州建设做出更大贡献。

市卫健委副主任隋晓琳、市卫健委行政审批科科长刘权、荆州市中心医院副院长汤绍迁及相关科室负责人参加评审会。
